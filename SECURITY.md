# Security

No release is supported yet. This is a planning-stage repository. Planned command execution uses the current user's privileges and is not a security sandbox.

Report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/zeyadomran/z/security/advisories/new). Do not put credentials, tokens, personal files, or exploit details in public issues. Include the affected revision, reproduction steps using an owned fixture, and the observed impact.
