- Execute nothing from a partial stream, and discard incomplete assembled tool calls. Docs confirm tool and thinking blocks cannot be partially recovered.
- Job Objects are described as lifecycle grouping, not isolation.
- Kill-on-close, with no silent unowned fallback.
- Never auto-replay unknown commands.
- Dropping a Tokio child alone is insufficient.
- No live database on network or synced storage.
- Original history stays separate from compacted context, as in fx. The checkpoint-before-switch rule also matches fx.
